# Kurage Web Order（kweborder）

FAX や電話で受けている注文を、取引先が自分で WEB から入れられるようにする **BtoB の WEB 受注システム**。
PHP 8 と SQLite だけで動く。レンタルサーバーにフォルダごと置けば動き、常駐プロセスもデータベースサーバーも要らない。

デモ: https://proto.exbridge.jp/kweborder/ （取引先 demo@example.com ／ demo2026、商社 admin.php admin ／ demo2026）

## できること

**取引先の画面（index.php）**
- メールアドレスを ID にして自分で登録（確認メールのリンクで本人確認）。パスワードの再設定もメールで
- 1社に複数人：最初の人が会社を登録（商社が承認してから注文できる）、2人目からは会社の**招待コード**で同じ会社に入る
- **品番で注文**：品番と数量を行で並べる。品番は途中まで打つと候補が出る。Enter で次の行
- **出荷先**：会社で共有する出荷先を何か所か登録し、注文ごとに選ぶ
- 注文履歴と状態（注文受付・受注済・出荷手配中・出荷済・完了）。受注済になる前なら取り消せる

**商社の画面（admin.php）**
- 受注一覧（状態・取引先・期間・番号で絞り込み）、まとめて受注済
- 状態を進める：注文受付 →（受注済＝注文の成立）→ 出荷手配中 → 出荷済 → 完了。変えると取引先にメール
- キャンセル：得意先は受注済になる前（注文受付）まで自分で取り消せる。商社は出荷済にする前（注文受付・受注済・出荷手配中）までキャンセルできる。注文受付のうちは「お断り」もできる
- 出荷予定日・運送会社・送り状番号はどれも任意。受注済の時点から入れられ、状態を変えずに直すこともできる。入っていれば取引先のメールと画面・CSV に出る
- 取引先の承認・停止、取引先コード（基幹の得意先コード）の登録
- **得意先別の価格**を CSV（品番,単価）で取り込み
- 商品（品番）を CSV（品番,品名,単位,標準単価,有効）で取り込み
- **CSV 書き出し**（明細1行が1行・BOM 付き UTF-8）

## 単価の決まり方

1. 得意先別の価格があれば、それ
2. 無ければ商品マスタの標準単価
3. それも無い品番（商品マスタに無い品番・標準単価が空の品番）は、取引先が単価を入力して注文する

どれを使ったかは明細ごとに「単価の出どころ」として記録し、CSV にも出す。取引先が入力した単価がある注文は、受注一覧に「単価要確認」と出る。

## CSV の列（固定）

受注番号, 注文日時, 状態, 受注日時, 取引先コード, 取引先名, 注文者, 注文者メール, 得意先注文番号, 出荷先名, 出荷先郵便番号, 出荷先住所, 出荷先電話, 希望納期, 行, 品番, 品名, 数量, 単位, 単価, 単価の出どころ, 金額, 注文合計, 備考, 出荷予定日, 運送会社, 送り状番号, 入力経路

支払い・請求は扱わない（基幹システムで行う前提）。

## 置き方

1. `public/` の中身をサーバーのフォルダ（例: `/order/`）に置く
2. `kwo_config.php.example` を `kwo_config.php` にコピーして書き換える（`demo => false`）
3. `kwo_data/` に Web サーバーが書き込めるようにする（初回アクセスで SQLite が作られる）
4. heteml などで PHP の版を指定する必要があるサーバーは `.htaccess` の `AddHandler` を合わせる

`kwo_data/` と `kwo_config.php` は `.htaccess` で外から読めないようにしてある。

## FAX で注文してくる取引先

WEB に移れない取引先の FAX は、[Kurage OCR Work](https://github.com/katsushi2441/kocrwork) で読み取って受注にできる。
